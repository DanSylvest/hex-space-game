# Hex Space Game

Минимальный прототип космической hex-игры.

## Поле боя

Для первой версии выбрано поле `21x11`.

Причина: у поля с четной шириной и высотой (`20x10`) центр находится между клетками. На `21x11` есть одна настоящая центральная клетка:

```txt
col = 10
row = 5
```

Она используется как клетка выхода.

## Что уже есть

- Phaser-сцена с hex-полем.
- Центральная клетка выхода.
- Два корабля, две стороны боя.
- Клик по доступной клетке задает ход игрока.
- Сервер на Fastify + WebSocket держит бой в памяти.
- Если сервер не запущен, клиент работает в локальном demo-режиме.
- Shared-пакет содержит правила hex-сетки и расчета хода.

## Запуск

```bash
npm install
npm run dev:server
npm run dev:client
```

Клиент: `http://localhost:5173`

Сервер WebSocket: `ws://127.0.0.1:3001/ws/combat`
